# Dureksha Arangala – Personal Portfolio | https://durekshaa-portfolio.vercel.app/

A responsive personal portfolio showcasing my data science projects, technical skills, certifications, education, and leadership experience as a final-year Data Science undergraduate at Sri Lanka Technology Campus (SLTC).

## 🚀 Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Dark and Light Modes:** Theme switching with a black-and-yellow or white-and-yellow design.
- **About Me:** Academic background, achievements, and professional profile.
- **Technical Skills:** Programming, data science, machine learning, and other technical competencies.
- **Projects:** Showcase of data science, machine learning, deep learning, and big data analytics projects.
- **Certifications and Experience:** Professional development, achievements, and leadership activities.
- **Contact and CV:** Easy access to my CV, GitHub, LinkedIn, and contact information.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/DurekshaArangala/Dureksha-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Dureksha-Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
